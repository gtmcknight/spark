On GitHub

        
    
          
  1. Fork gtmcknight/spark. In your fork, open Actions and click I understand my workflows, go ahead and enable them.
    2. 
          
  2. Open config.json in your fork, click the pencil, replace everything with this, and commit. It draws the chart above.
            
    3. 
          
  3. Go to Settings → Secrets and variables → Actions and leave the tab open. Your X keys go here.
    4. 
        

        
On X

        
    
          
  1. Open the X Developer Console and create an app.
    2. 
          
  2. In the app, open User authentication settings. Set permissions to Read and write, type to Web App, Automated App or Bot, and put https://spark.rhps.fun in both Callback URI and Website URL. Save.
    3. 
          
  3. Open Keys and tokens. Under OAuth 1.0 Keys, regenerate the Consumer Key, then generate the Access Token. X shows each secret only once, so add each to GitHub as it appears: New repository secret, named as in the table.
            
    
              
    Consumer Key, the key
    
              
    Consumer Key, the secret
    
              
    Access Token, the token
    
              
    Access Token, the secret
    
            
    
            Skip OAuth 2.0 (Client ID and Client Secret); this doesn't use them. The Access Token should say Read and write. If it says Read, you made it before step 5, so regenerate it.
    4. 
        

        
Back on GitHub

        
    
          
  1. Go to Actions → Update bio → Run workflow. Your bio changes within a minute, then twice a day.
    2. 
        

        
X bills each update to your developer account, so keep a little credit under Billing. Twice a day costs a few cents.
